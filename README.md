# Snek-analysis-Mx
Herramienta CLI automatizada para análisis forense de memoria que envuelve Volatility 3. Identifica OS, procesos sospechosos, inyecciones de DLL, conexiones de red activas y genera reportes HTML interactivos. Diseñada para acelerar la respuesta a incidentes y el análisis de malware en entornos Windows/Linux/macOS.
